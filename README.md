# Sticky & Note

Standalone Android notes app combining sticky notes and Google Keep-style organization.

## Planned features
- Notes with tabs/categories
- Add and rename tabs
- Search, pin, archive and delete notes
- Dark theme
- Resizable Android home-screen widget
- Offline local storage
- Google Keep synchronization
- GitHub Actions APK builds
- Release signing with a persistent signing key

The private Android signing keystore is intentionally not stored in this repository.
